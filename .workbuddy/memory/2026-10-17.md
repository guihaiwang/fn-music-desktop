## 通用滚动条组件 Scrollbar（src/components/Scrollbar.vue，仿 el-scrollbar）
- 结构：container(overflow:hidden) > wrap(原生滚动+隐藏原生滚动条 scrollbar-width:none/::-webkit-scrollbar) > view；叠加绝对定位自绘滑轨/滑块 → 滑块不占内容宽高
- 滑块算法（el 同款无测量技巧）：height = clientH/scrollH*100% of 轨道；translateY = scrollTop/clientH*100%（translate % 参照自身高度），两端数学上精确对齐；ratio>=1 时该方向滑块 v-show 隐藏
- Props：height/maxHeight（数字px|字符串，作用于 wrap）、native（还原原生滚动条）、always（常显 vs 悬停/拖动时显示，纯 CSS opacity 切换+pointer-events 联动）、tag、wrapClass/wrapStyle/viewClass/viewStyle；emit scroll{scrollTop,scrollLeft}
- 交互：滑块拖动（mousedown+window mousemove，dScroll = delta*clientH/thumbH，body userSelect 置 none 防选中）、点轨道跳转（滑块中心对齐点击位，与 el 一致）
- 尺寸自愈：ResizeObserver 同时观察 wrap 与 view（内容增删/容器变化自动 update），native 切换 watch 重建；expose wrapRef/update/scrollTo/setScrollTop/setScrollLeft
- CSS 变量可定制：--fnm-scrollbar-thickness(8px)/thumb-color/thumb-color-hover（默认按本应用暗色调 rgba 白）
- 类型注意：<script setup> 里 export type 有兼容风险（已去掉，文档示例用 InstanceType<typeof Scrollbar>）；scrollTo 重载实现需按 typeof 分支调用，cast 后同调 (ScrollToOptions, number) 会撞 native (number,number) 重载

## Scrollbar 遮挡修复 + 编辑封面验证（收尾）
- 遮挡根因：自绘滑块 pointer-events:auto 且常驻 DOM（仅 opacity 0），不可见时也拦截右缘点击/悬停；滑块贴 right:2px 直接压在菜单/歌单/"+"按钮上（收起 66px 时尤其明显）
- 修复方案（组件层）：bar 默认 opacity:0 + pointer-events:none，由 `.fnm-scrollbar:hover > bar` / is-always / is-dragging 三态恢复 opacity:1+pointer-events:auto（悬停触发靠容器 :hover，bar 自身 PE 不参与，无死锁）
- 修复方案（aside 层，顶层规则不用嵌套 :deep()）：`.aside-content :deep(.fnm-scrollbar__wrap){padding-right:10px}` 给内容预留滑块留白；`--fnm-scrollbar-thickness:6px`；`.is-collapsed` 时 bar display:none + padding-right:0（窄内容直接隐藏滑块，滚轮仍可滚）
- aside 顺手改：Scrollbar 加 class="aside-scroll" width:100%（父级 align-items:flex-start 会收缩）；.playlist-name 由固定 135px 改 flex:1+min-width:0 防横向溢出；横向 bar 在 aside display:none

- agent-browser 验证全通过：展开态滑块 168-174px 与按钮右缘 166px 无重叠、elementFromPoint 命中按钮/歌单；收起态 bar display:none；编辑弹窗回填名称+封面、上传→裁剪→封面替换、恢复原封面按钮、保存后 mock /playlist/edit 调用 1 次 + "编辑歌单成功" toast
