### API 逆向结论（来自 NAS http://192.168.1.125:5666/music 的 JS bundle 分析，关键 chunk: 5e884898...B563oObE.js）
- API Base: `http://<nas>:5666/music/api/v1`，统一响应 `{code, msg, data}`，code=0 成功
- 端点表：`GET /sys/config`（含 nasOAuth.clientId）、`POST /user/auth-login`、`POST /user/password-login`（password=sha256 hex）、`GET /user/me`、`POST /user/logout`
- authx 签名 header（每个请求必带）：
  `nonce=<6位随机>&timestamp=<ms>&sign=<md5(SECRET_path_nonce_ts_bodyHash_apiKey)>`
  - SECRET=`NDzZTVxnRKP8Z0jXg1VAMonaG8akvh`（SparkMD5，hex；bodyHash: GET→md5(decodeURIComponent(sortedQuery))，POST→md5(JSON body)，无 body→md5("")）
- 鉴权：cookie `music-token=<userToken>`；deviceId=32位hex（uuid 去横线），localStorage 持久化
- SSO：`{origin}/signin?client_id=<clientId>&redirect_uri=<enc(/music/oauth/result)>&app_name=飞牛音乐` → 登录成功 302 回 redirect 带 `?code=` → auth-login 换 userToken
- 本 NAS 实测 clientId=`EDDLUH2WLY`，serverName=foolin-wang，serverVersion=1.0.10
